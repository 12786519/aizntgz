# TASK-013 验证 M1 端到端闭环

## 关联需求

R-002：课程资料拉取和手动上传。

R-003：六类格式解析、切片、向量化与索引。

R-004：任务状态与失败重试。

## 目标

使用六类真实样本验证从资料进入到授权检索、带引用答案返回的 M1 闭环。

## 输入 / 输出

- 输入：六类真实样本、测试租户、授权用户和未授权用户。
- 输出：端到端测试报告、失败任务记录和性能数据。

## 允许修改

- tests/e2e/test_ingestion_to_retrieval.py（新建）
- tests/fixtures/（新增或修改）
- docs/ACCEPTANCE-验收清单.md
- docs/PLAN-实施计划.md

## 禁止

- 不得为通过测试降低权限校验或跳过失败场景。
- 不得修改原始需求或测试样本来规避缺陷。
- 不得新增依赖。

## 验收标准

- [ ] 六类真实样本均可完成入库并被授权用户检索并得到带引用答案。
- [ ] 未授权用户无法获得内容或引用。
- [ ] 失败样本的状态、原因和重试结果可查询。
- [ ] 记录检索耗时并形成 M1 验收证据。

## 测试命令

pytest tests/e2e/test_ingestion_to_retrieval.py -q
