# TASK-008 实现标准文本切片器

## 关联需求

R-003：对解析文本进行切片。

## 目标

将各解析器输出转换为可保留来源元数据的可控大小文本切片。

## 输入 / 输出

- 输入：标准文本块、切片大小和重叠参数。
- 输出：有序切片列表，每个切片保留文档、页码或时间戳来源。

## 允许修改

- src/ingestion/chunker.py（新建）
- tests/ingestion/test_chunker.py（新建）
- docs/OPEN-QUESTIONS-待确认事项.md

## 禁止

- 不得决定未确认的切片大小、重叠比例或语言策略。
- 不得写数据库或调用向量服务。
- 不得新增依赖。

## 验收标准

- [ ] 切片顺序稳定且来源元数据不丢失。
- [ ] 长文本按已确认的参数切分，短文本不被无意义拆分。
- [ ] 空文本返回空列表且不抛异常。
