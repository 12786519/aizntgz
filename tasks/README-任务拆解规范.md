# 任务拆解规范

## 任务卡要求

- 一个任务预计 0.5–1 天完成。
- 一个任务仅关联 1–3 条需求。
- 一个任务允许修改的文件建议不超过 5 个。
- 每张任务卡必须包含：关联需求、目标、输入/输出、允许修改、禁止、验收标准、测试命令和状态。
- 未确认的业务规则必须列为前置条件或任务阻断项，不能自行假设。
