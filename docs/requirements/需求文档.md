# RAG 知识库 SaaS 平台需求文档

> 来源：项目方案页 rag-saas-platform-plan.html。本文为工程输入整理，未经业务方签署的条目均视为待确认。

## 项目范围

本期新增 RAG 入库、智能检索和智能体三大模块。已有课程、订单、支付、代理分销、用户权限、邮件和审计服务通过 API 复用，不重复开发。

## 功能需求

1. 知识库支持行业、课程资料、合规、企业文化四类分类及子分类。
2. 课程资料从旧系统拉取；非课程资料支持手动上传。
3. 支持 PDF、XLS、PPT、DOCX、图片、MP4 的解析、切片、向量化与索引。
4. 入库任务须可查询状态、失败重试、处理版本更新。
5. 检索须先执行登录、购买、课程有效期和知识库范围校验，再返回答案和资料引用。
6. 学习助手支持已购课程答疑、试题解析、学习计划与订单/课程/进度查询。
7. 大客户报表智能体支持订单/学习数据汇总、汇报材料和邮件发送。
8. 机构统计智能体支持销售、学员、课程热度统计、图表和导出。
9. 智能客服作为独立功能，支持售前咨询、FAQ 和转人工。

## 非功能要求

- 多租户隔离，权限粒度下钻到课程和文档。
- 入库失败可重试；变更同步必须可追踪、可对账、可恢复。
- 检索响应 P95 目标不高于 5 秒。
- 支持审计、日志脱敏和敏感数据保护。

## 需签署确认

文件限制、MP4 检索口径、切片参数、购买与有效期规则、旧系统接口 SLA、报表指标、客服转人工流程和合规要求，详见 docs/OPEN-QUESTIONS-待确认事项.md。
